# VS Code Devcontainer for Cataclysm: Dark Days Ahead

## Overview

This folder contains VS Code and Docker configuration files and image definitions required to perform development of Cataclysm: Dark Days Ahead (CDDA) within an Ubuntu linux based Docker container.

For details on how VS Code's devcontainer feature works, see Microsoft's documentation on VS Code's Remove Development Extensions that support this workflow: https://code.visualstudio.com/docs/remote/create-dev-container

## For Developers Using Other Editors

While this folder is intended to make the development experience of VS Code a plug-and-play setup, the Docker configurations and image definitions themselves should be usable directly from Docker. Any editor that supports editing over a SSH connection should be sufficient.
